# 多空证据双分支替代决策体系

原 8 节点线性链（数据→信号→采证→决策→对抗→复审→风控→报告）以 TRADE/WATCH/PASS 决策为终点，但使用者希望自己裁决方向，且线性拓扑未发挥 LangGraph 的并行能力。重构为：确定性数据/信号层 → 两个并行分支（bull_research / bear_research 同时消费同一份冻结快照、互不可见）→ 确定性证据核验 → 单文档证据陈列。系统不再产出方向性结论——decision/confidence/对抗/风控/校准整体退役，避免 LLM 隐式推荐污染使用者判断；证据客观性由三层保证：basis 结构化引用可机器核验、双分支独立采证、同一数据两面解读并列呈现。

**Considered Options**:
- 保留决策体系仅并行化：仍会产生隐式方向推荐，违背"自己裁决"诉求，被否决。
- 分支内部自我挑战（多头分支自找反证）：把对抗环节前置回 LLM 主观，与"独立采证"冲突，被否决。
- 证据带置信度字段：LLM 自评信心分是主观臆想，被否决（信心由使用者依据 basis 自行判断）。

**Consequences**:
- 校准回看失去 decision 分桶对象，decision 型校准退役；信号快照随 run.json 落盘，"信号 vs 价格"校准列为后续票。
- 报告层新增确定性证据核验，取代原风控终审的机器强制位置。
- 历史序列深挖（TVL/fees/stablecoin）从 LLM 工具改为确定性趋势特征落盘，LLM 只读数值不转述曲线。
